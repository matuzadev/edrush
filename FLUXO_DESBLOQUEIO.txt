       └─ 36 relações total


✅ APIs REST (4 novas rotas)

   GET  /api/chapters/progress
   ├─ Retorna todos capítulos + progresso do usuário
   └─ Mostra locked/unlocked status

   POST /api/chapters/progress
   ├─ Submete resultado após completar capítulo
   ├─ Automaticamente DESBLOQUEIA próximos se 80%+
   └─ 🔥 Core da magic

   GET  /api/chapters/[id]/questions
   ├─ Carrega 10+ questões da dificuldade pedida
   └─ JSON com opcoes, resposta_correta, etc

   POST /api/chapters/submit-answer
   └─ Registra cada resposta para analytics


✅ FRONTEND PRONTO

🚀 COMO COMEÇAR (3 MINUTOS)
═════════════════════════════════════════════════════════════════════════════

Passo 1: Instalar deps Python
   $ pip install -r scripts/requirements_populate.txt

Passo 2: Popular banco (2-5 min)
   $ export TURSO_DATABASE_URL="libsql://seu-db.turso.io"
   $ export TURSO_AUTH_TOKEN="seu-token"
   $ python scripts/populate_chapters_questions.py

Passo 3: Configurar desbloqueios (10 sec)
   $ python scripts/setup_chapter_unlocks.py

Passo 4: Rodar server Next.js
   $ npm run dev

Passo 5: Testar em http://localhost:3000
   └─ Use o código de exemplo em QUICK_START_BLOCKS.md
